# Локальный ИИ — подключение своей модели (по желанию)

Программа **полностью работает без ИИ**. Локальная модель — дополнительный помощник:

| Где | Что делает |
| --- | --- |
| Мастерская → «ИИ: угадай, что дальше» (или **Alt+A**) | Предлагает 1–6 строк кода серым текстом в месте курсора. **Tab** — принять, **Esc** — отказаться |
| Мастерская → «Что под курсором» → «Объясни иначе (ИИ)» | Объясняет строку своими словами, по-русски |
| Мастерская → ошибка после запуска → «Спросить у локального ИИ» | Причина + исправленные строки (сам код не меняет) |
| Переводчик ошибок → «Спросить ещё и локальный ИИ» | Объяснение ошибки, которой нет в базе |

Ответы ИИ **всегда** помечены «Догадка ИИ — может ошибаться» и **ничего не меняют сами** — только по
твоему нажатию. Программа разрешает только адреса **на этом компьютере** (`localhost`, `127.0.0.1`):
код никуда в интернет не уходит.

## Вариант 1 — Ollama (проще всего)

1. Установи Ollama: <https://ollama.com> (Windows-установщик).
2. Скачай модель для кода, которая помещается в 8 ГБ (выбери одну):
   ```
   ollama pull qwen2.5-coder:7b      # лучше всего для кода, ~4.7 ГБ
   ollama pull qwen2.5-coder:3b      # быстрее, если компьютер слабый, ~1.9 ГБ
   ollama pull llama3.2:3b           # общая модель, хорошо объясняет по-русски, ~2 ГБ
   ```
3. Ollama после установки работает сама (значок у часов).
4. В программе: **⚙ Настройки → Локальный ИИ** → галочка «Использовать…» → Программа:
   **Ollama** → адрес `http://localhost:11434` → **Проверить** → выбери модель в списке.

## Вариант 2 — LM Studio / llama.cpp / Jan (OpenAI-совместимый сервер)

1. LM Studio: <https://lmstudio.ai> → скачай модель (например *Qwen2.5-Coder-7B-Instruct, Q4_K_M*).
2. Вкладка **Developer** (Local Server) → **Start Server** (порт `1234`).
3. В программе: Программа: **LM Studio / llama.cpp / Jan** → адрес `http://localhost:1234/v1` →
   **Проверить** → модель.

Для `llama.cpp`: `llama-server -m model.gguf --port 8080` и адрес `http://localhost:8080/v1`.

## Если «не получается достучаться»

- **Установленная программа (.exe)** ходит к ИИ сама — ничего настраивать не нужно. Проверь только,
  что Ollama / LM Studio запущены и адрес верный.
- **В браузере** (переносная версия) сервер ИИ должен разрешать страницу программы:
  - Ollama: задай переменную среды `OLLAMA_ORIGINS=*` и перезапусти Ollama
    (Windows: «Изменение системных переменных среды» → «Переменные среды» → «Создать»).
  - LM Studio: в настройках сервера включи **CORS**.
- Слабый компьютер: выбери модель поменьше (3b) — ответы будут быстрее. «Длина ответа» по умолчанию
  ограничена, чтобы маленькие модели не «болтали».

## Как это устроено (для любопытных)

- `src/code/ai/localAi.ts` — настройки, проверка адреса (только этот компьютер), запросы к
  `/api/tags` и `/api/generate` (Ollama) или `/v1/models` и `/v1/chat/completions` (OpenAI-совместимые).
- В программе для ПК запрос делает сама программа (`desktop/main.cjs`, канал `mf:ai-request`) — она
  тоже проверяет, что адрес локальный. Страница не получает доступа ни к файлам, ни к интернету.
- Подсказки для маленьких моделей короткие и строгие: «ответь только кодом, 1–6 строк» /
  «2–4 коротких предложения по-русски».
