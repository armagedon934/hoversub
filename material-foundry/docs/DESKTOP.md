# Программа для ПК (Windows .exe с установщиком)

Папка `desktop/` превращает приложение в обычную программу для Windows: установщик с выбором папки,
ярлыки на рабочем столе и в «Пуске», удаление через «Приложения». Внутри — Electron 44 (тот же
Chromium, что в браузере) и файлы программы; интернет не нужен.

## Как получить установщик

**Способ 1 — GitHub Actions (на настоящей Windows, без своих инструментов).**
Workflow `.github/workflows/desktop-installer.yml` на каждый push (и вручную: Actions →
«Desktop installer (Windows)» → *Run workflow*) собирает установщик на Windows, **устанавливает его
в папку `C:\MF Test\Material Foundry`, запускает установленную программу в режиме самопроверки**
(`--smoke-test`: открывает программу, раздел кода, редактор, проверяет файлы Python и грамматик),
удаляет её и выкладывает `MaterialFoundry-Setup-1.0.0.exe` в **Artifacts** этого запуска
(хранится 30 дней).

**Способ 2 — собрать самому на Windows** (нужен Node.js 20+):

```
cd material-foundry
npm ci
npm run build
cd desktop
npm ci
npm run dist:win
```

Готовый файл: `material-foundry/desktop/release/MaterialFoundry-Setup-1.0.0.exe`.
(На Linux тоже собирается, но нужен Wine с 32-битной частью: `wine64` + `wine32:i386`.)

**Запустить без установки (для проверки):** `cd desktop && npm start`.

## Что в установщике

- Шаги: лицензия (RU/EN) → «Только для меня / Для всех пользователей» → **выбор папки**
  (по умолчанию `%LOCALAPPDATA%\Programs\Material Foundry`) → установка → «Запустить».
- Язык установщика — по языку Windows (русский или английский).
- Ярлыки «Material Foundry» на рабочем столе и в меню «Пуск»; деинсталлятор
  `Uninstall Material Foundry.exe`. Данные пользователя (прогресс, файлы Мастерской) при удалении
  не стираются.
- Тихая установка (для администраторов): `MaterialFoundry-Setup-1.0.0.exe /S /D=C:\Путь\К\Папке`.

## Безопасность программы для ПК

- Страница не имеет доступа к Node.js (`contextIsolation`, `sandbox`), окна и переходы на сайты
  заблокированы (ссылки https открываются в обычном браузере).
- Файлы программы отдаются через собственную схему `app://` только из папки программы; строгая
  политика CSP — никакого кода из интернета.
- Единственный «мост» к компьютеру — запрос к **локальному** ИИ (`localhost`), с проверкой адреса.
- Установщик **не подписан** цифровой подписью (подпись платная) — Windows SmartScreen может
  предупредить: «Подробнее» → «Выполнить в любом случае».

## Что проверено (честно)

- Программа для ПК (Linux-сборка того же Electron 44) — автоматическая проверка
  `xvfb-run -a npm run e2e:desktop`: 13/13 (материалы, Мастерская: C# и Python, Мини-Unity, локальный
  ИИ через программу, CSP, изоляция, запрет переходов). Самопроверка `--smoke-test` — проходит.
- Установщик Windows собран и проверен **под Wine**: окна лицензии, выбора «для кого», **выбора
  папки**; тихая установка в `C:\Games\Material Foundry` (файлы, `app.asar` с программой, ярлыки на
  рабочем столе и в «Пуске», деинсталлятор) и удаление. Под Wine установщик ложно сообщает
  «Material Foundry is running» (известная особенность Wine) — для этой проверки собиралась копия
  без проверки запущенной программы; в выдаваемом установщике проверка оставлена.
- Сам Windows-exe программы под Wine окно не открыл (Electron под Wine не работает надёжно), поэтому
  запуск на **настоящей** Windows проверяет workflow GitHub Actions (установка → `--smoke-test`).
