# «Понять код» — инструкция на русском

Программа объясняет любой код простыми словами, учит программированию (уроки, курсы, мини-игры),
помогает **писать свой код** (подсказки «что дальше», проверка ошибок, безопасный запуск) и даёт
поиграть со своими скриптами Unity в **Мини-Unity**. Всё работает на твоём компьютере, без
интернета.

Безопасность в двух предложениях: файлы, которые ты **открываешь**, только читаются и **никогда не
запускаются**. Выполняется только код, который ты сам пишешь в «Мастерской», — и только когда ты
нажмёшь «Запустить», внутри закрытой песочницы без доступа к файлам и интернету.

## 1. Установить на компьютер

### Вариант А — установщик для Windows (рекомендуется)

1. Возьми файл `MaterialFoundry-Setup-1.0.0.exe` (как его получить — в [DESKTOP.md](DESKTOP.md)).
2. Запусти его. Установщик — обычный, по шагам:
   лицензия → «для меня / для всех пользователей» → **выбор папки** (кнопка «Обзор…») →
   установка → «Запустить Material Foundry».
3. Появятся ярлыки на рабочем столе и в меню «Пуск». Удаление — как у любой программы
   («Параметры → Приложения» или «Uninstall Material Foundry.exe» в папке программы).

Если Windows покажет синее окно «Windows защитила ваш компьютер» — нажми «Подробнее» →
«Выполнить в любом случае» (у программы нет платной цифровой подписи).

### Вариант Б — переносная версия (без установки, любая система)

1. Скачай архив `material-foundry/release/MaterialFoundry-portable.zip`.
2. Распакуй **весь** архив и дважды щёлкни `Start-Windows.bat` / `Start-Mac.command` /
   `Start-Linux.sh`. Откроется браузер. Не закрывай маленькое чёрное окно, пока работаешь.

При первом запуске сразу открывается **«Понять код»**. Кнопка **«Материалы»** вверху — это вторая
часть программы: студия текстур и 3D-моделей (её интерфейс на английском). Программа запоминает,
какую часть ты открывал последней.

## 2. С чего начать

Сверху всегда есть жёлтая строка-подсказка: **что сделать сейчас**. На первом экране:

| Кнопка | Для чего |
| --- | --- |
| ▶ **Продолжить с того места, где остановился** | Один щелчок — и ты снова в своём уроке, уровне или файле |
| 🎮 **Учиться с нуля** | Короткие уроки и курсы с анимацией и мини-играми |
| 🛠 **Писать свой код** | «Мастерская»: редактор, который подсказывает, проверяет и запускает |
| 🕹 **Мини-Unity** | Пиши настоящие скрипты Unity и смотри, как они двигают героя |
| 🔍 / 📂 | Посмотреть пример или открыть свой проект и разбирать его |
| 🩹 **Перевести ошибку** | Вставь красный текст из Unity / Visual Studio — получи объяснение |

## 3. Учиться

Вкладка «Учиться» разделена на четыре части:

- **Уроки** — 8 уроков на выбор: C#, C++, C, Python, JavaScript. Каждый: «Узнай» → «Смотри по
  шагам» → 3–4 мини-игры → звёзды и опыт. Кнопка **«Сравнить с другими языками»** показывает тот же
  код на других языках рядом — видно, что идея одна, меняется только написание.
- **Курсы**:
  - **C# для Unity — 16 уроков**: типы, if, for, while, массивы, List, методы, классы, свойства,
    наследование (`virtual`/`override`), `enum` и `switch` (состояния врага), Dictionary, `$"…"`,
    LINQ, `try/catch`, векторы. Каждый пример **по-настоящему выполняется** — в пошаговом
    просмотре видны настоящие значения. В конце урока — **задание**: пишешь код, нажимаешь
    «Запустить и проверить», программа сравнивает, что выведено, с тем, что нужно.
  - **C# дальше (часть 2) — 9 уроков** с заданиями: `static`, `struct` и `class` (почему `Vector3`
    копируется и откуда ошибка CS1612), интерфейсы (`IDamageable`), `Action`/`Func`, события `event`
    (шаблон «наблюдатель»), обобщения `<T>`, `?.`/`??`/`??=`, `const`/`readonly`, перебор `Dictionary`.
  - **Unreal Engine C++ — 4 урока**: Actor, `BeginPlay`/`Tick`, `UPROPERTY`, `.h`/`.cpp`,
    указатели и `IsValid`, функции для Blueprints — всё в сравнении с Unity. (C++ здесь не
    запускается — это сказано прямо; вместо запуска — проход по строкам с объяснениями.)
- **Тренажёры** (по 5 минут в день, всё про Unity C#):
  - 🐞 **Найди баг** — 26 настоящих ошибок Unity. Сначала видишь **симптом** («игрок не двигается,
    ошибок нет»), нажимаешь на неправильную строку, получаешь объяснение и исправленную строку.
    Ошибки, найденные не с первого раза, попадают в «Повторение».
  - 🔮 **Что выведет код?** — бесконечные вопросы (каждый раз новые числа) по 15 темам: деление
    целых, остаток, циклы, `x++`, `if/else`, `$"…"`, `List`, `Mathf.Clamp`, `while`/`break`, методы…
    Правильный ответ вычисляется **настоящим запуском кода**, а каждый неправильный вариант объясняет
    своё типичное заблуждение («ты поделил как калькулятор — int / int отбрасывает дробь»). Есть
    «Посмотреть по шагам» и серия правильных ответов подряд.
  - 🔄 **Порядок событий Unity** — расставь `Awake → OnEnable → Start → FixedUpdate → Update →
    LateUpdate → OnDisable → OnDestroy`.
  - 📍 **Куда писать этот код?** — Update, Start, LateUpdate или FixedUpdate?
  - 📋 **Шпаргалка Unity C#** — самые нужные строки на одной странице; можно скачать `.md` или
    распечатать.
  - 🏅 **Достижения** (20 штук) и 🎯 **цель дня** (50 опыта) — кольцо цели видно и на первом экране.
- **Повторение** — чтобы не забывать. Вопросы из пройденных уроков и твоего блокнота
  возвращаются через 1, 2, 4, 8 и 16 дней. «Помню» — карточка уходит дальше, «Забыл» —
  возвращается раньше. Хватает 5 минут в день.
- **Блокнот** — всё, что ты сохранил кнопкой ⭐, и твои заметки. Можно сохранить файлом `.md`.

## 4. Мастерская — писать свой код

Слева — редактор, справа — три вкладки: **Подсказки**, **Хочу…**, **Результат**.

**Три слоя помощи при наборе:**

1. **Список слов с объяснениями.** Набираешь `transform.` или `Input.` — появляются
   `Translate`, `position`, `GetKeyDown`, `GetAxis`… и у каждого — объяснение по-русски.
   После `rb.` (если `rb` — это `Rigidbody2D`) — `AddForce`, `linearVelocity`… Работает и для твоих
   переменных: программа сама находит их тип.
2. **«Что дальше» — серый текст.** Программа знает обычный порядок скрипта Unity:
   `using UnityEngine;` → класс → поля → `Start`/`Update` → движение → прыжок → триггеры.
   Внутри пустого `Update` она предложит `float x = Input.GetAxis("Horizontal");`, на следующей
   строке — `transform.Translate(x * speed * Time.deltaTime, 0, 0);`.
   **Tab** — принять, **Esc** — скрыть. Справа в «Подсказках» — те же идеи с объяснением, *почему*
   так обычно пишут.
3. **Что под курсором** — объяснение слова, на котором стоит курсор (кнопка ⭐ сохраняет в блокнот).

**Проверка на лету** (красное/жёлтое подчёркивание + список «Проблемы» с кнопкой «Исправить»):
пропущенная `;` или `}`, `update` с маленькой буквы (Unity такой метод **молча не вызывает**!),
`transform.position.x += 1` (ошибка CS1612), `=` вместо `==`, `if (...);`, `float x = 5.5` без `f`,
`Debug.log` вместо `Debug.Log`, движение без `Time.deltaTime`, `GetComponent` в `Update`,
`while` в `Update`, `OnTriggerEnter2D(Collider other)` вместо `Collider2D`, класс не совпадает с
именем файла, нет `using UnityEngine;`, `new` для MonoBehaviour. Для Python: нет `:`, `print "…"`,
`input()+1`. Для C/C++: `scanf` без `&`, `cout` без `std::`.

**«Хочу…»** — напиши своими словами: «хочу чтобы персонаж прыгал», «собирать монетки», «камера
следит за игроком», «враг преследует», «пауза», «сохранить рекорд»… Найдётся готовый рецепт
(их 50: движение, прыжок с физикой, 3D-ходьба, монеты, счёт на экране, здоровье, урон, стрельба,
враги, спавн, таймер, перезапуск, пауза, сохранения, корутины, звук, анимации, кнопки, луч,
дверь и ключ, ScriptableObject, Unreal, C++, C, Python, JavaScript). У каждого — что он делает,
**что настроить в редакторе Unity**, пояснения к важным строкам. «Новый файл» или «Вставить».

**Запуск** (кнопка «Запустить» или Ctrl+Enter):

- **C#** — по-настоящему, шаг за шагом. Если программа спрашивает (`Console.ReadLine`) — появится
  поле для ответа. Потом **«Посмотреть по шагам»**: какая строка выполняется, «коробки» со значениями
  (изменившиеся подсвечены), в какой функции мы сейчас, что на экране. Значения — настоящие.
- **Скрипт Unity** (`: MonoBehaviour`) — кнопка превращается в «Играть в Мини-Unity».
- **Python** — настоящий Python (первый запуск ≈10 секунд), с `input()` и пошаговым просмотром.
- **JavaScript** — выполняется с выводом (`console.log`, `prompt`).
- **C и C++** — честно: здесь не запускаются (нужен компилятор), но проверки и объяснения работают.
- Бесконечный цикл останавливается и объясняется. Ошибки объясняются: что значит и как исправить.

Файлы Мастерской хранятся внутри программы. «Открыть» делает **копию** файла с компьютера
(оригинал не меняется), «Скачать» сохраняет копию на компьютер.

## 5. Мини-Unity

14 уровней, каждый учит одну идею Unity: `Start` и `Debug.Log` → `Update`, `transform.position`,
`Time.deltaTime` → `Input.GetKey` → `OnTriggerEnter2D`, `CompareTag`, `Destroy` → `GetAxis` →
`Rigidbody2D` и прыжок → `Instantiate` (стрельба) → таймер → финальный уровень → **корутина**
(`WaitForSeconds`) → **`InvokeRepeating`** → **прыжок только с земли** (`Physics2D.Raycast`; без
проверки героя уносит в шипы) → **`FindWithTag`** → **массивы и `foreach`** (магнит для монет).

1. Прочитай задание. 2. Измени код слева. 3. Нажми «Играть», щёлкни по игре и жми стрелки/пробел.
Справа — **Inspector** (поля твоего скрипта во время игры) и **Console** (`Debug.Log`).
Застрял — «Подсказка»; после двух попыток можно открыть решение. Ошибки в духе Unity
(CS1612, бесконечный цикл в `Update`, нет `MonoBehaviour`) — с объяснением.
Скрипт из Мастерской запускается в **«Песочнице»** (земля, платформы, монеты, враг, флаг):

- **все 39 Unity-рецептов из «Хочу…» в ней работают** и делают то, что обещают (новые: двойной
  прыжок, рывок на Shift, возрождение после падения, враг-стрелок, самонаводящийся враг, маршрут по
  точкам, текст диалога по буквам, регенерация, магнит для монет, комбо-счётчик, победа при сборе всех
  монет, враг разворачивается у препятствия лучом); ходьба, прыжок с
  физикой и проверкой земли, 3D-ходьба с CharacterController, вращение, поворот к мыши, стрельба
  (пробел или клик мышью), враг преследует / патрулирует, движущаяся платформа, спавнер, таймер,
  пауза (`Time.timeScale`), перезапуск (`SceneManager.LoadScene`), корутины
  (`yield return new WaitForSeconds`), Animator, звук, луч (`Physics2D.Raycast` + `Debug.DrawRay`
  виден на экране), текст счёта и полоска здоровья на экране;
- скрипт **сам вешается на подходящий объект**: скрипт врага — на врага, платформы — на платформу,
  спавнера и камеры — на невидимые объекты;
- **пустые поля Inspector заполняются сами** (как будто ты перетащил объект), и каждое такое
  заполнение написано в Console: `groundCheck ← точка у ног героя`, `groundLayer ← слой Ground`,
  `firePoint ← точка перед героем`, `bulletPrefab ← префаб пули`…

**🏗 Проект: свой платформер** (кнопка вверху Мини-Unity) — один скрипт, который за 5 шагов
превращается в маленькую игру: ходьба → прыжок с земли (луч) → монеты → прыжок на врага сверху →
сообщение о победе. Каждый шаг начинается с кода предыдущего и проверяется автоматически.

Мини-Unity понимает большую часть того, что пишут новички, но не всё; если чего-то нет — она
честно об этом скажет.

## 6. Переводчик ошибок

Вкладка «Ошибки»: вставь текст из Console Unity, Visual Studio, компилятора C++, Python или
браузера. Для каждой ошибки: где (файл и строка), **что это значит**, **как исправить**. 52 вида
ошибок: CS0103, CS1002, CS1061, CS0246, CS1612, NullReferenceException, MissingReferenceException,
UnassignedReferenceException, IndexOutOfRange, LNK2019, segmentation fault, NameError,
IndentationError…

## 7. Фокус и удобство (СДВГ)

- **Фокус** (кнопка вверху) — таймер 10/15/25/45 минут, затем мягкий перерыв на 5 минут
  (голосом: «встань, попей воды»).
- **🔊** рядом с объяснениями — прочитать вслух (голос системы, без интернета). Скорость — в настройках.
- **Шрифт для лёгкого чтения** (настройки) — спокойный шрифт PT Sans, больше расстояние между буквами.
- Размер текста, «просторно» между строками, светлая/тёмная тема, подсказки вкл/выкл.
- Всё запоминается: язык, прогресс, файлы, блокнот, повторение, «где остановился».

## 8. Локальный ИИ (по желанию)

Программа полностью работает без ИИ. Если на компьютере есть своя модель (Ollama или LM Studio),
её можно подключить: **Настройки → Локальный ИИ**. Подробно — [LOCAL_AI.md](LOCAL_AI.md).
Что умеет: «ИИ: угадай, что дальше» (Alt+A) в Мастерской, «Объясни иначе (ИИ)», «Спросить у
ИИ, как исправить ошибку». Ответы ИИ всегда помечены «Догадка ИИ — может ошибаться» и вставляются
только по твоему нажатию. Разрешены только адреса на этом компьютере.

## 9. Разбор своего проекта

Как раньше: слева файлы, в середине код, справа объяснение. Уровни 1–5, «Не понимаю»,
«Покажи на примере», «Где создаётся / используется», схемы, «О проекте» (распознаёт Unity и
Unreal), «А что если изменить?» с предпросмотром и отменой. Хорошо понимает C, C++ и C#
(указатели, `->`, `::`, `#include`, `new`/`delete`, `virtual`, свойства, события, LINQ, методы
Unity, макросы Unreal, векторы).

## 10. Честно об ограничениях

- Открытые проекты **не запускаются** — поэтому в разборе проекта значения во время работы
  помечены «Неизвестно». Запускается только код в Мастерской, курсах и Мини-Unity.
- C# выполняется собственным пошаговым интерпретатором: он понимает то, что пишут новички
  (переменные, условия, циклы, массивы, List, Dictionary, классы, свойства, наследование, enum,
  LINQ, исключения, векторы), но не всё C#. Если чего-то нет — он скажет это прямо.
- Мини-Unity — маленький 2D-мир с большой частью API Unity (включая корутины, `Physics2D`, мышь,
  `Animator`, `CharacterController`), а не настоящий движок: нет 3D, сцен, префабов из файлов и
  настоящей физики столкновений (`OnCollisionEnter2D` не вызывается).
- C и C++ не запускаются (нужен компилятор); JavaScript — без пошагового просмотра.
- Подсказки «что дальше» основаны на правилах (обычный порядок скриптов), а не на «понимании»
  твоих намерений; ИИ-догадки могут ошибаться.
- Установщик не подписан цифровой подписью — Windows может предупредить при первом запуске.
