# «Понять код» — инструкция на русском

Программа объясняет любой код простыми словами и учит программированию через короткие уроки
с мини-играми. Всё работает на твоём компьютере, без интернета. Код, который ты открываешь,
**никогда не запускается**, а твои файлы не меняются без твоего ясного «да».

## 1. Скачать и запустить

1. Скачай архив `material-foundry/release/MaterialFoundry-portable.zip` из репозитория
   (на GitHub: открыть файл → кнопка «Download raw file»).
2. Распакуй **весь** архив в любую папку (например, на Рабочий стол).
3. Дважды щёлкни:
   - **Windows:** `Start-Windows.bat`
   - **macOS:** `Start-Mac.command` (в первый раз: правый щелчок → «Открыть» → «Открыть»)
   - **Linux:** `Start-Linux.sh`
4. Откроется браузер. Не закрывай маленькое чёрное окно, пока пользуешься программой.

Если Windows покажет синее окно «Windows защитила ваш компьютер» — нажми «Подробнее» →
«Выполнить в любом случае». Для macOS и Linux нужен Python 3 или Node.js (обычно уже есть).
Лучше всего работает в Chrome или Edge.

## 2. С чего начать (программа сама подскажет)

Сверху всегда есть жёлтая строка-подсказка: **что нажать сейчас**. Нужная кнопка мягко
подсвечивается. Подсказки можно выключить в «Настройках».

На первом экране три больших варианта:

| Кнопка | Для чего |
| --- | --- |
| 🎮 **Учиться с нуля** | Короткие уроки (≈3 минуты) с анимацией и мини-играми |
| 🔍 **Посмотреть пример** | Маленькая программа-магазин: нажимай на любое слово и читай объяснение |
| 📂 **Открыть свой код** | Папка или файлы с компьютера, любой язык |

## 3. Уроки и игры («Учиться»)

1. Выбери язык: **C#** (игры на Unity), **C++** (Unreal Engine, быстрые программы), **C**,
   **Python** (самый лёгкий старт), **JavaScript** (сайты и браузерные игры).
2. Нажми большую кнопку «Твой следующий шаг».
3. Каждый урок — 4 шага:
   - **Узнай** — одна мысль и маленький кусочек игры (здоровье героя, урон, волна врагов…);
   - **Смотри, как работает** — программа выполняется по шагам: подсвечивается текущая строка,
     видно «коробки» с данными (переменные), «Где мы сейчас» (в какой функции программа и кто
     ждёт ответа) и что появляется на «Экране». Кнопки «Назад», «Следующий шаг», «Само по шагам»;
   - **Играй** — 3–4 мини-игры: «Что будет на экране?», «Найди ошибку» (нажми на неправильный
     значок), «Расставь строки по порядку»;
   - **Готово** — звёзды, очки опыта (XP), уровень и «дней подряд».
4. Уроки: переменные → условия → циклы → игровой цикл → функции → списки → объекты →
   указатели (для C и C++).

Каждая программа из уроков на C, C++, Python и JavaScript по-настоящему компилируется и
запускается в автоматических тестах — анимация показывает ровно то, что напечатает программа.

## 4. Разбор своего кода

- Слева — файлы. В середине — код. Справа — объяснение того, на что ты нажал.
- **Уровни 1–5**: «Как ребёнку», «Новичок», «Техничнее», «Глубоко», «Научи» (упражнение).
- **Не понимаю** — объяснит по-другому, проще (каждый раз новой фразой).
- **Покажи на примере** — маленький пример той же идеи.
- **Где это создаётся?**, **Где используется?** — переход и подсветка.
- Картинки: **Шаги** (кнопка «Покажи по шагам» подсвечивает строки по очереди), **Функции**
  (кто кого вызывает), **Данные** (где значение создаётся, меняется и читается), **Файлы**.
- **О проекте** — что это за проект, с чего начинается, главные части; распознаёт игровые
  проекты Unity и Unreal Engine.
- **А что если изменить?** — выбираешь цель простыми словами, видишь предпросмотр «было/станет»,
  риски и проверку записи. Изменение применяется только после твоего подтверждения, в копию
  внутри программы, с точкой восстановления. Отменить можно всегда (Ctrl+Z или «Изменения»).
- Каждое утверждение помечено: **Проверено**, **Вероятно**, **Догадка** или **Неизвестно**.

### Что программа особенно хорошо понимает в C, C++ и C#

Указатели `*`, адрес `&`, стрелку `->`, `::`, `#include`/`#define`, `new`/`delete`,
`malloc`/`free`, деструкторы `~`, `virtual`/`override`, ссылки, шаблоны `<T>`, свойства C#
`get`/`set`, события `event`, `int?`, LINQ, `main`; методы Unity (`Start`, `Update`,
`OnCollisionEnter`…), макросы Unreal (`UCLASS`, `UPROPERTY`, `UFUNCTION`), `BeginPlay`/`Tick`,
векторы (`Vector3`, `FVector`), списки и словари; известные функции (`printf`, `malloc`,
`std::cout`, `Console.WriteLine`, `Debug.Log`, `Instantiate`, `GetComponent`, `Time.deltaTime`…).

## 5. Настройки

Кнопка **⚙ Настройки**: язык (Русский/English), тёмные/светлые цвета, размер текста,
расстояние между строками, подсказки вкл/выкл, список клавиш.

## 6. Честно об ограничениях

- Программа **не запускает** твой код, поэтому не знает значений во время работы — это
  всегда помечено «Неизвестно».
- Связи между файлами ищутся по именам («Вероятно»).
- Swift разбирается только «по словам» (полная грамматика Swift роняет браузер Chromium).
- Сохранить изменения прямо в папку можно в Chrome/Edge; в других браузерах — скачать ZIP.
- Проверка записи ловит ошибки синтаксиса, но не доказывает, что программа работает правильно.
